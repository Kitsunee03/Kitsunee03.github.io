## Project notes

Junkonaut is built around a simple physical loop: collect space junk, feed it to the Glorious Hole, and use the resulting progression to improve the tools that make the next cleanup run faster and more satisfying.

### Movement and tools

The vacuum handles the main cleanup interaction, while the grapple gun makes it possible to move between planets and asteroids. The jetpack rounds out the movement system and gives the player control while exploring the surrounding space.

### What to look for

The current build focuses on the core interaction loop, the upgrade curve, and the strange characters encountered along the way. It is intentionally presented as a compact prototype, so the page keeps the technical details and controls close to the playable version rather than hiding them in a separate section.
